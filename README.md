# 从 0 用 Vibe Coding 开发商业级 Windows 软件：超级快捷键 · 众筹落地页

爱学啊教育出品。

课程的宣传页：一页长图文，手机优先，电脑上也适配。录课程介绍视频时，直接对着这个页面从上往下讲。

| 文件 | 内容 |
|---|---|
| `index.html` | 全部文字和页面结构，从上往下就是页面顺序 |
| `styles.css` | 样式（先写手机，`min-width: 720px` 以上放宽成电脑布局），配色和软件官网一致 |
| `main.js` | 交互：功能视频滑到眼前才播放；手机上点“下载”给出电脑网址；付款、介绍视频还没定时的提示 |
| `assets/` | 图标、截图、功能演示视频（从软件官网复制） |

纯静态网页，不依赖任何框架，不用编译。本地预览：

```bash
python -m http.server 5180
```

然后打开 http://localhost:5180/。

## 发布前要填的内容

全部在 `main.js` 最上面的 `CONFIG` 里，填好就生效；空着时页面上给出“即将公布”之类的提示，不会出错：

| 字段 | 填什么 |
|---|---|
| `planLinks.standard`、`planLinks.full` | 两个档位在课程网站上的课程页网址，点“参与众筹”直接跳过去 |
| `wechat.id`、`wechat.qr` | 客服微信号；二维码图片放到 `assets/wechat-qr.png` 后把 `qr` 改成这个路径 |
| `videoUrl` | 课程介绍视频的 B 站地址（首屏大封面） |
| `bilibili`、`douyin` | 账号名和主页地址；都空着时底部不显示这一行 |

页面里如果临时写了占位文字，用 `<span class="todo">…</span>`（黄底），发布前全部替换掉。

## 约定

- 不写参考软件的名字；不放私有仓库的源码。
- 视频、截图放在 `assets/`，演示视频 960×600、几十 KB 到 200 KB；大的介绍视频放 B 站，这里只放封面。
